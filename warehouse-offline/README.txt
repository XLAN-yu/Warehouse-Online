仓储台 · 离线浏览器工程包
==========================

使用方法
1. 解压整个文件夹，保持 index.html、app.css、app.js 在同一目录。
2. 双击 index.html，建议使用 Microsoft Edge 或 Google Chrome。
3. 所有商品、出入库、盘点和流水数据保存在当前浏览器的本机存储中，不会上传网络。

包含功能
- 多商品入库与出库
- 品名、商品编号联想查找
- 严禁负库存
- 移动加权平均成本
- 库存盘点和盘盈盘亏
- 库存日报、月报、年报
- Excel 导出
- JSON 手动备份与恢复
- 商品资料和自动/人工编号

注意事项
- 请勿使用浏览器“清除网站数据/缓存”功能，否则本机库存可能被删除。
- 建议每周在“数据备份”页面下载一次 JSON 备份。
- 不同浏览器、不同 Windows 用户之间的数据互不相通。
- 图片 OCR 需要额外识别模型，为保证本工程包完全离线，当前离线版不包含 OCR；线上版仍支持 OCR。
- 本离线版适合单机使用。多人跨电脑协作请使用线上版。

文件说明
- index.html：离线入口
- app.css：界面样式
- app.js：全部业务逻辑与本机数据存储
