仓储台 · 离线浏览器工程包（空白正式数据版）
==========================================

使用方法
1. 完整解压压缩包，不要在压缩包内部直接运行。
2. 双击“启动仓储台.cmd”，系统会自动打开默认浏览器。
3. 使用期间请保留启动窗口；关闭窗口后，离线网站会停止运行。
4. 首次启动没有演示商品或演示单据，请先在“商品资料”中建立商品。

数据保存位置
- 所有商品、库存、入库、出库、盘点和流水自动写入 data\warehouse-data.json；该文件会在首次启动时自动创建。
- 自动及手动备份保存在 data\backups 文件夹。
- 系统每周自动备份一次，并自动删除超过 30 天的备份。
- 整个文件夹可以复制到其他 Windows 电脑继续使用，复制前请先关闭启动窗口。

包含功能
- 多商品入库与出库
- 品名、商品编号联想查找
- 入库选择已有商品时自动带出上次实际单价，仍可手工修改
- 入库选择商品后自动带出其默认供应商，供应商输入框支持一键清空
- 出入库最后一个输入框按 Enter 可直接提交
- 严禁负库存
- 出库用途未填写时先提示，并可点击红色“忽略用途”按钮继续且保留忽略记录
- 移动加权平均成本
- 库存盘点和盘盈盘亏
- 库存日报、月报、年报
- 日报、月报和年报可选择任意日期、月份或年份查看
- Excel 导出
- JSON 自动备份、手动备份与恢复
- 商品资料和自动/人工编号
- 工作台使用指引与全局字体大小设置
- 工作台全局搜索：支持按供应商、商品编号、商品名称联想查找，并可直接发起入库、出库
- 全局搜索结果按商品名称、编号、供应商、库存、价格、状态和操作分栏显示
- 商品名称和中文供应商支持拼音首字母搜索，例如“语文”可输入“yw”查找
- 工作台顶部左侧固定显示日期、右侧显示全局搜索；点击两块内容外的深绿色边缘可打开教程
- 入库遇到新商品时自动打开商品资料补全窗口
- 新商品资料补全到最后一项时按 Enter，可直接建立商品并自动完成原入库单
- 新增商品窗口会预填下一个 ZERO 商品编号；编号可一键清空后改为人工编号，任意输入项按 Enter 可直接提交
- 入库自动补建商品窗口支持窗口级 Enter 提交，兼容不同电脑上的浏览器操作
- 入库、出库完成后自动返回工作台并显示本次操作资料卡
- 操作资料卡放大显示，10 秒后淡出，也可主动关闭
- 商品资料和查看库存中的供应状态均可直接修改
- 五种供应状态依次使用绿、黄、橙、蓝、红显示，切换后颜色立即更新
- 点击库存商品进入独立的全周期页面，以表格查看建库、历次入库、出库和盘点明细
- 商品全周期记录可单独导出 Excel
- Excel 使用标准 .xlsx 格式，避免扩展名与文件格式不匹配提示
- 零库存商品可移除；有库存商品需二次确认后清空并移除
- 左侧常驻“撤回上一步”，保留最近 20 次可撤回操作
- 标准 100%、较大 120%、特大 150% 三档显示大小
- 调整全局字体时左侧导航栏视觉宽度保持稳定，只放大其中的文字和按钮内容
- 工作台日期卡和全局搜索卡保持相同高度
- 设置中可选择移动加权平均、先进先出或最近入库价；新方式只影响之后的出库成本
- 切换计价方式后，工作台库存金额、查看库存计价单价、全局搜索和 Excel 导出会同步采用当前方式
- 出库完成资料卡和商品全周期会显示实际使用的计价方式及出库成本

注意事项
- 不要直接双击 index.html；浏览器无法在未启动本地服务时写入 data 文件夹。
- 不要在网站运行时移动、删除或重命名 data 文件夹。
- 如需迁移数据，请完整复制整个解压后的仓储台文件夹。
- 图片 OCR 需要额外识别模型，为保证本工程包完全离线，当前离线版不包含 OCR；线上版仍支持 OCR。
- 本离线版适合单机使用。多人跨电脑协作请使用线上版。

文件说明
- 启动仓储台.cmd：Windows 启动入口
- server.ps1：离线网页与本地数据保存程序
- index.html：网页入口（请勿直接双击）
- app.css：界面样式
- app.js：全部业务逻辑
- data\warehouse-data.json：首次启动后自动生成的正式业务数据文件
- data\backups：自动及手动备份文件夹

重新生成离线包
- 在工程根目录双击“生成离线包.cmd”（它会以兼容方式调用 build-warehouse-package.ps1）。
- 脚本会先删除 dist-packages 中旧的“仓储台-离线浏览器工程包*.zip”，再生成一个最新压缩包。
- 脚本只清理旧压缩包，不会读取或打包运行后生成的 data\warehouse-data.json。
