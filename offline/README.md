# Signal Lab 离线版

这是一个无需服务器、无需登录、无需联网的浏览器工具包。所有采样、变换、卷积和时频立方体计算都在本机浏览器中完成。

## 使用

1. 完整解压此文件夹；不要只复制 `index.html`。
2. 双击 `index.html`，或右键选择 Chrome、Edge、Safari、Firefox 打开。
3. 浏览器可断网使用。

## 分享

将整个 `Signal-Lab-Offline` 文件夹压缩后发送给同学或组员。对方解压后即可打开，不需要访问 `chatgpt.site`，也不会遇到该站点的 Cloudflare 拦截页。

## 说明

此压缩包已经包含浏览器运行所需的文件；使用者不需要安装 Node.js、Python、MATLAB 或任何服务器软件。若要修改工具功能，请在完整的 Signal Lab 源码工程中更新后，再生成新的离线包。
